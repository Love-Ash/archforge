# W21: A rare color painted beside a dominant near-identical one

| | |
|---|---|
| Severity | warning |
| Category | render |
| Profiles | full |

## What it means

A color painted a handful of times right beside a near-identical color used throughout the deck -- what a mistyped hex looks like from the outside. Counting distinct colors would only measure genre, so the gate measures the shape of the mistake instead: the pair must be lopsided (the dominant color painted at least 6x more often, redmean distance at or under 16), and neither member may carry more than two near neighbours, which is what separates a deliberate gradient ramp from a slip -- the guard the first corpus sweep forced. Judged deck-wide rather than per page, because a stray is only visible against the whole palette. Thresholds are measured on 148 decks, where 95% report nothing and the worst reports two. Runs in the full profile only while the thresholds soak.

## How to fix

Unify the stray color with the dominant one beside it; if both are intentional, move them further apart.

## If you disagree

False-positive reports with a repro deck are the most valuable contribution this project takes: use the [FP template](https://github.com/Love-Ash/archforge/issues/new/choose). Calibration rationale lives in [docs/CALIBRATION.md](../CALIBRATION.md).

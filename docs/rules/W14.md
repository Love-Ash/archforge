# W14: Titles are noun phrases, not claims

| | |
|---|---|
| Severity | warning |
| Category | style |
| Profiles | full |

## What it means

Most titles are nominal phrases rather than claims. Hangul titles use a sentence-ending heuristic minus the nouns whose last syllable collides with one (개요, 투자, 사용자, 게임); English titles count a finite verb (measured allowlist) or number+unit as a claim. Structural titles are not eligible in either language (cover, agenda, appendix / 표지, 목차, 감사합니다). Prefer false negatives on ambiguous verb/noun forms. Read the --ghost list top to bottom: it should tell a story.

## How to fix

Rewrite as action titles (the --ghost list should read as a story). Editorial decks: --skip W14.

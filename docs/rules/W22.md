# W22: Text crossed by a hairline rule

| | |
|---|---|
| Severity | warning |
| Category | geometry |
| Profiles | full |

## What it means

A glyph run crossed by a hairline rule: a thin solid divider whose centerline passes through the interior of the text's glyph box, covering at least half of the run along its own axis -- what an unintended strikethrough looks like. The evidence case is an arrow glyph impaled on the lower end of a vertical divider. Readability gates stay silent there (contrast is fine, no second text, no picture), which is why this is its own rule. A rule shape is textless, unrotated, at most 0.06in thick, at least 0.8in long at a 15:1 aspect; underlines and section dividers sit outside the glyph box and never intersect it, so they pass by geometry rather than by exception. Runs in the full profile only while the thresholds soak on the corpus.

## How to fix

Move the text off the rule, or end the rule before it reaches the text.
